# portobyiqbal

Personal data analyst portfolio website showcasing interactive business intelligence dashboards, data analyses, and verified credentials.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion
- **Smooth Scroll**: Lenis
- **Charts & Visualizations**: Recharts
- **Document Rendering**: PDF.js (`pdfjs-dist`)
- **Icons**: Lucide React
- **Typography**: Inter Tight

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- pnpm (or npm / yarn)

### Installation

```bash
pnpm install
```

### Development

Start the local development server:

```bash
pnpm run dev
```

### Production Build

Typecheck and compile the production bundle:

```bash
pnpm run build
```

Preview the production build locally:

```bash
pnpm run preview
```
